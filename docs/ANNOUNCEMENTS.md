# Release Announcement Template

Template for broadcasting releases to Telegram channel subscribers:

```markdown
🚀 **OptimAI Telegram Node vX.Y.Z Released!**

**What's New:**
- ✨ New command: `/xyz`
- 🛠️ Improved error recovery and supervisor stability
- 📖 New runbook: `docs/RUNBOOK.md`

**Upgrade Guide:**
Run `docker compose pull && docker compose up -d` to upgrade with zero state loss.
```
