# Contribution and Pair Credit Standards

All PRs must satisfy the repository quality bar:

1. **Small Diffs**: Focused, atomic commits solving one problem.
2. **Test Validation**: `make check` passes with 0 failures before push.
3. **Co-author Credit**: `prepare-commit-msg` hook appends authorized co-author trailers.
4. **Fast Merges**: Automated CI validates byte-compilation and docker configuration.
